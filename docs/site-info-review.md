# 교회 안내 입력 후보

| 항목 | 공식 웹사이트에서 확인한 내용 | 적용 전 확인 |
| --- | --- | --- |
| 교회명 | 선한목자 젊은이교회 | 현재 공식 표기 |
| 주일예배 | 주일 오후 3시, 글로리홀 6층·샬롬홀 지하 1층 | 공사 중 장소·시간 변동 |
| 소개 | 2006년 청년부에서 독립해 창립했고 2024년 구조와 방향을 재편해 재창립했다고 안내 | 공개용 요약 문구 |
| 비전 | “예수님과 동행하며 닮아가는 증인들이 모인 선교적 공동체” | 현재 사용 문구 |
| 주소 | 경기도 성남시 수정구 성남대로 1518번길 9 (복정동) | 실제 출입구와 지도 링크 |
