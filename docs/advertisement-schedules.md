# 광고 일정 입력

관리자 주보 편집 화면에서 **광고 → 일정 추가**를 누릅니다. 기존 세부 내용의 **내용 타입**을 **일정**으로 바꿔도 됩니다. 하나의 광고에 신청 기간과 행사 일시 등 여러 일정을 등록할 수 있습니다.

- **제목**과 **시작 날짜**를 입력합니다.
- 하루 일정은 종료 날짜를 비워도 됩니다. 기간 일정은 종료 날짜를 입력합니다.
- 하루 전체 또는 여러 날 전체 일정은 **종일**을 선택합니다. 종일 기간에는 시작일부터 종료일까지 모두 표시됩니다.
- 시각을 지정하려면 종일을 해제하고 **시작 시각**을 입력합니다. 같은 날의 종료 시각은 선택이며, 여러 날에 걸친 일정은 종료 시각도 입력합니다. 모든 시각은 한국 시간 기준입니다.
- 안내 내용에는 장소나 기타 설명을 입력할 수 있습니다. 비워 두면 캘린더에서 광고 설명을 표시합니다.

**모바일 미리보기**에서 저장 전에도 일정 표시를 확인할 수 있습니다. 새 주보는 저장 후 **발행**해야 공개 캘린더에 표시되고, 발행된 주보의 일정은 변경 내용을 저장하면 반영됩니다. 여러 달에 걸친 일정은 각 달의 날짜에 표시되며 월별 목록에는 한 번씩 나옵니다. 다음 날 00:00에 끝나는 시간 지정 일정은 직전 날까지만 날짜 표시를 합니다.

공개 캘린더는 교회 안내에 직접 등록한 일정과 모든 발행된 광고의 일정을 함께 표시합니다. 다음 주 주보로 바뀌어도 이전 광고의 일정은 유지됩니다. 같은 광고 제목·일정 제목·날짜·시각으로 반복 등록한 일정은 하나로 표시합니다. 일정 변경·삭제는 해당 광고에서 수정합니다.

일정 데이터는 기존 `promotions.details` JSON에 저장하므로 이 기능을 위한 데이터베이스 마이그레이션은 필요하지 않습니다. 기존 일반 세부 내용은 그대로 읽고 수정할 수 있습니다. 공개·관리자 주보 조회 API는 발행된 광고에서 계산한 `calendarEvents`를 함께 반환합니다.
